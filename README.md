# Redis 학습 및 기능 검증 기록

단순 Key-Value 저장 수준을 넘어 Redis의 자료구조, TTL 관리, 동시성 제어, 분산 시스템 개념을 직접 검증하기 위해 학습 내용을 단계별로 정리했습니다.  
각 기능은 실제 서비스에서 활용 가능한 시나리오를 기준으로 테스트 및 구현을 진행했습니다.

---

# RedisTemplate 학습 기록

## Chapter 1. String 자료구조 (`opsForValue`)

가장 기본적인 Key-Value 저장 방식입니다.

### 학습 내용
- 데이터 저장 및 조회
- TTL(Time To Live) 기반 자동 만료 처리
- 단순 캐싱 구조 확인

### 적용 예시
- 이메일 인증번호 저장
- 로그인 세션 관리
- 단순 조회 캐시

---

## Chapter 2. List 자료구조 (`opsForList`)

순서가 있는 데이터를 저장하기 위한 자료구조입니다.

### 학습 내용
- Push / Pop 동작 확인
- 범위 조회 테스트
- FIFO 구조 검증

### 적용 예시
- 최근 조회 상품 목록
- 간단한 메시지 큐

---

## Chapter 3. Set 자료구조 (`opsForSet`)

중복을 허용하지 않는 자료구조입니다.

### 학습 내용
- 데이터 중복 방지
- Set 기반 검색
- 집합 연산 확인

### 적용 예시
- 상품 태그 관리
- 태그 중복 검증

---

## Chapter 4. Sorted Set 자료구조 (`opsForZSet`)

Score 기반 정렬 기능을 제공하는 자료구조입니다.

### 학습 내용
- Score 기반 정렬
- 범위 조회
- 랭킹 데이터 관리

### 적용 예시
- 실시간 인기 검색어
- 게임 랭킹 시스템
- 경매 종료 시간 관리

---

## Chapter 5. Hash 자료구조 (`opsForHash`)

하나의 Key 내부에 여러 필드를 저장할 수 있는 자료구조입니다.

### 학습 내용
- 필드 단위 데이터 수정
- 특정 필드 조회
- 객체 형태 데이터 관리

### 적용 예시
- 사용자 프로필 관리
- 사용자 상태 정보 저장

---

# Redisson 및 분산 시스템 학습 기록

## Chapter 1. 분산 락 기초 (`RLock`)

동시 요청 상황에서 데이터 정합성을 유지하기 위한 분산 락 동작을 학습했습니다.

### 학습 내용
- `lock()` / `unlock()` 동작 확인
- `waitTime`, `leaseTime` 설정
- 동시 요청 테스트

### 적용 예시
- 경매 입찰 충돌 방지
- 중복 요청 제어

---

## Chapter 2. AOP 기반 분산 락 적용

비즈니스 로직과 락 처리 로직 분리를 목적으로 AOP 기반 분산 락 구조를 학습했습니다.

### 학습 내용
- 커스텀 어노테이션 작성
- AOP 기반 락 처리
- 공통 로직 분리

### 적용 예시
- 서비스 로직 분리
- 재사용 가능한 동시성 처리 구조 구성

---

## Chapter 3. 트래픽 제어 및 보호 기능

과도한 요청 상황에서 서버를 보호하기 위한 기능을 검증했습니다.

### 학습 내용
- `RRateLimiter` 적용
- 동시 요청 제한
- 요청 수 제어 테스트

### 적용 예시
- 비정상 반복 요청 제한
- 선착순 기능 제어

---
